## 문제 요약

문자열 S, T와 Q개의 질의. 각 질의는 L, R을 주고
**S의 L번째~R번째 부분문자열이 T를 부분문자열로 포함하는지** 묻는다.

|S| ≤ 4×10⁵, |T| ≤ 10, Q ≤ 2×10⁵

## 접근

질의마다 `S.substr(L-1, R-L+1)`에서 T를 찾으면 O(Q·|S|)로 터진다.
**T의 출현 위치를 미리 다 구해두고** 질의마다 이분 탐색한다.

1. 전처리 — S를 훑어 T가 시작되는 인덱스를 전부 `idx`에 모은다. |T| ≤ 10이라
   단순 비교로 O(|S|·|T|)면 충분하다. `idx`는 자연히 오름차순이 된다.
2. 질의 — `lower_bound(idx, L-1)` 로 **L 이후 첫 출현**을 찾는다.
   그 하나만 보면 된다. 더 뒤의 출현은 끝 위치가 더 크므로 R 안에 들어갈
   가능성이 첫 출현보다 낮다.
3. `idx[f] + |T| <= R` 이면 Yes.

O(|S|·|T| + Q log|S|). 최대 입력(|S|=4×10⁵, Q=2×10⁵)에서 0.27초.

## 함정

`lower_bound` 결과가 `end()`인 경우를 놓치면 범위 밖을 읽는다.
L이 T의 마지막 출현보다 뒤면 `f == idx.size()`가 되는데, `if(idx.size())`는
벡터가 비었는지만 막을 뿐 이 경우를 막지 못한다.

```
1
abbaba
ab
6 6
```

그냥 돌리면 답이 맞게 나오고 ASan으로 돌려야 heap-buffer-overflow로 잡힌다.
abc176 D의 `mapp[-1]`과 같은 유형 — 로컬에서는 정답, 채점에서는 RE.

```bash
g++ -O1 -g -std=c++17 -fsanitize=address,undefined -o main_san abc477_C.cpp
```

## 다른 풀이

| 방법 | 비고 |
|---|---|
| 출현 위치 + 이분 탐색 | 이 코드. |T| 가 작아 전처리가 싸다 |
| 누적합 | `cnt[i]` = i까지의 출현 횟수. 질의는 O(1) — 더 간단하다 |
| 다음 출현 위치 배열 | `nxt[i]` = i 이상에서 첫 출현. 전처리 O(|S|), 질의 O(1) |
| KMP / Z-algorithm | |T| ≤ 10 이라 굳이 필요 없다 |
